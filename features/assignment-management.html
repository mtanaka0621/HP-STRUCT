アサイン管理の仕組み

STRUCTのアサイン管理は4つの概念で構成され、スタッフの入社から退社まで一貫して稼働を管理します。

01
アサイン枠
Assignment Frame
入社から退社までアサイン可能な期間。パートナー企業スタッフの場合は有効契約期間を指します。入社日登録と同時に自動生成されるため、漏れが発生しません。
02
アサインリクエスト
Assignment Request
PMがプロジェクトへの参加を申請すること。リクエストは管理者に提出され、承認後にアサイン予定としてスケジュールされます。
03
アサイン予定
Scheduled Assignment
リクエスト承認後に確定したプロジェクトへの参加予定。組織全体の稼働バランスを見ながら最適な配置を管理します。
04
アサイン実績
Assignment Achievements
タイムシートから提出されたアサイン時間。予定と実績を比較し、稼働計画の精度を継続的に改善できます。
Staff Master

スタッフ登録で
アサイン枠を自動生成

スタッフマスタに登録すると、入社日（パートナー企業スタッフは発注書）をもとにアサイン枠が即座に自動生成されます。これにより、登録漏れゼロを実現します。

管理できるマスタデータ一覧
組織マスタ・役職マスタ・スキルマスタ・スタッフマスタ・スタッフ＆組織マスタ
  • スタッフ写真・自己紹介動画を登録可能
  • クラス（職種・単価）を紐付け管理
  • パートナー企業スタッフも一元管理
Resume & Self-PR

スキル・実績の
可視化でマッチング

すべてのスタッフが履歴書・スキルセット・自己紹介動画を登録し、アサイン担当者へアピールします。

マネージャーはリッチなプロフィールを参照して最適なスタッフを選定。スタッフ側も動画・職歴の充実でアサイン機会を増やせます。

登録できる情報：学歴・職歴・担当プロジェクト・スキルタグ・自己PR動画・自己紹介文
Assignment Request

リクエストを一元集約し
仕組みを標準化

PMからのアサインリクエストはすべて管理者へ一括送信されます。組織全体のスケジュールを俯瞰しながら、最適なスタッフ配置を判断できます。

収益性（マージン・ROI）を比較して最適なプロジェクトへアサイン。属人的な判断を排除し、データに基づく意思決定を実現します。
  • 承認フローで透明性を確保
  • 組織全体の稼働状況を確認しながら判断
  • アサイン予実の月別比較が可能
Assignment Adjustment

入れ替わりの激しい現場を
一画面で直感的に差配

アベイラブルなスタッフの把握から案件への配置確定まで、すべてをひとつの画面で完結。IT・SIer・コンサル業界に特有の、入れ替わりが激しいアサイン業務を、特許取得済みの独自アルゴリズムで根本から効率化します。

スタッフカードを案件にドラッグするだけでアサインが確定。受注金額・利益率・対象期間をポップアップで即確認でき、採算を考慮した意思決定をその場で行えます。
  • 自社・協力会社のアベイラブルスタッフを一覧表示
  • アサイン時間の超過・不足をハイライトで自動検知
  • 月次ガントで中長期のリソース計画を可視化
  • 特許取得済みの独自アルゴリズムを搭載
Internal Case Management

社内案件の収支から
アサインまで一括管理

見落とされがちな社内プロジェクトも、収支進捗・月次予算・スタッフアサインをSTRUCT一画面で管理。プロジェクトごとの稼働率設定も可能です。

管理できる社内案件情報：プロジェクト期間・担当組織・月別予算・アサインリクエスト予定・実績金額
  • 社内プロジェクトの収支を月別で確認
  • スタッフのアサイン時間を案件別に集計
  • 承認フローと連動した予算管理
