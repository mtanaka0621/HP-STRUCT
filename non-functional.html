非機能要件への対応とセキュリティ対策

STRUCTでは、お客様が安心してサービスをご利用いただけるよう、以下の非機能要件に対応しています。

ユーザー管理・認証方式

STRUCTはメールアドレスとパスワードを使用した独自のユーザー管理を実装しています。パスワードは暗号化して保存されます。また、過去1週間以内に使用履歴のないIPアドレスやデバイスからのアクセス時には、登録メールアドレスにワンタイムパスワード（6桁の数字）を送信する二段階認証を採用しています。

  • ユーザー管理方式：プロダクトDBでのユーザー管理
  • ユーザーID：任意設定可能
  • ワンタイムパスワード：あり
  • 顧客認証基盤との連携：可能（別途作業費）

自動ログアウト（セッションタイムアウト時間）

ログイン後、一定時間操作がない場合、自動的にログアウトされます。

  • ログアウトまでの時間：30分

機能へのアクセス制御

STRUCTでは、ロール単位で画面ごとにアクセス権を設定できます。ユーザーは複数のロールを保持でき、ログイン時に保持しているロールによって利用可能な機能が決まります。

  • 機能アクセス制限単位：画面単位、ユーザー単位でのアクセス制御（ロールあり）

データへのアクセス制御

STRUCTでは、ロールを使って画面・データ項目ごとにアクセス権（閲覧または作成・更新・削除）を設定できます。設定オプションは「全て拒否」「全て許可」「自部門が作成したデータのみ許可」「自分が作成したデータのみ許可」から選択できます。

  • データアクセス制限単位：画面単位、ユーザー単位でのアクセス制御（ロールあり）
  • 選択肢：全て拒否 / 全て許可 / 自部門作成データのみ許可 / 自分作成データのみ許可

データ削除方式

一般ユーザーによる削除は論理削除（データ無効化）です。論理削除後もデータへのアクセスは可能です。管理ユーザーには物理削除機能があります。物理削除されたデータはアクセス・復元できません。

  • データ削除方式：論理削除（管理ユーザーは物理削除可）

データ変更ログ（作成・更新・削除）

データ作成・更新時には実行日時とユーザーIDが記録されます。論理削除時も実行日時とユーザーIDが記録されます。STRUCT画面でデータの作成・更新・論理削除の記録を確認できます。

  • データ変更ログ記録タイミング：作成・更新・論理削除
  • 記録内容：各データに実行日時・ユーザーIDを記録

活動ログ（監査ログ）

STRUCTでは、ボタンクリック時に活動ログを記録します。実行時刻・実行ユーザー・実行操作が記録されます。データ検索・削除操作時は検索条件と対象データキーも記録されます。活動ログは当社へのリクエストにより提供可能です。

  • 活動ログ記録タイミング：サーバーへのリクエストを送信するボタン操作時
  • 記録内容：ログファイルに実行日時・ユーザーID・実行内容を記録

インフラ・データセンター

STRUCTはMicrosoft Azure上で構成されています。データセンターはAzureの東日本リージョンに配置されています。

  • インフラ：Microsoft Azure 東日本リージョン

フェイルオーバー対策

STRUCTは以下のフェイルオーバー対策を実施しています。

  • ネットワーク冗長化
  • 可用性ゾーン・可用性セットによる障害時のシステム継続

アーキテクチャ

データベースはMicrosoft Azure SQLを使用しています。ファイル・画像データはAzure Blob Storageに保存されます。複数のお客様が同じサービスを利用しますが、ログイン情報などの一部共有情報を除き、DBとストレージはお客様環境ごとに分離されています。

  • DB：Microsoft Azure SQL ※顧客ごとに別環境で保存
  • ファイル：Azure Blob Storage ※顧客ごとに別環境で保存

データ暗号化

STRUCTは以下の暗号化技術を採用しています。

  • 通信はHTTPSで暗号化
  • DBデータはTransparent Data Encryptionによりデータベースレベルで暗号化
  • パスワード・氏名などの機密性の高いカラムはAlways Encryptedにより列レベルで暗号化

WAF（Webアプリケーションファイアウォール）の導入

WAFはウェブアプリケーションをサイバー攻撃から保護するためのセキュリティ対策です。ウェブサイトへのアクセスを監視し、不正な通信を検知・ブロックすることで、SQLインジェクション・クロスサイトスクリプティングなどの攻撃を防止します。

  • WAF導入：済み

脆弱性対応

STRUCTの脆弱性対応はAzureのセキュリティ標準に準拠しています。

  • VMインスタンスおよびランタイムソフトウェアの定期更新
  • アプリとAzureリソース間の機密情報通信はAzure内に留まりネットワーク境界を越えない
  • 機密情報は常に暗号化して保存
  • App Serviceの接続機能（ハイブリッド接続等）を介した通信はすべて暗号化

データバックアップ

STRUCTは以下のサイクルでバックアップを実施しています。

  • DB：週次フルバックアップ、12時間差分バックアップ、約10分トランザクションログバックアップ
  • ファイル：週次フルバックアップ、12時間差分バックアップ
  • アクセスログ：週次フルバックアップ、12時間差分バックアップ

バックアップファイルの保持期間は1週間です。災害・システム障害発生時には、当社が復元可能な最新バックアップポイントへの復元を行います。特定ポイントへの復元を希望されるお客様には、別途作業費見積もりの上対応します。

データ削除

STRUCTサービス契約終了時、入力データおよび保管バックアップはすべて完全削除されます。解約後は契約を再開してもデータは復元できません。

  • 解約時のデータ削除：完全削除

データ抽出

解約前にデータ抽出を希望されるお客様には、別途作業費見積もりの上対応します。

  • データ抽出対応：あり（別途作業費）

システム監視

STRUCTでは、各種システム障害やバグ発生を検知するためにシステム監視を実施しています。タイムリーな障害検知をご希望のお客様には、別途作業費見積もりの上対応します。
